# ai-cai-tutor-supplementary
# Supplementary materials

**Article:** Design, implementation and technical evaluation of AI-CAI Tutor: A novel teacher-governed, curriculum-aligned generative AI tutoring platform for teaching and learning across educational levels in Ghana

**Journal:** Education and Information Technologies (submitted for anonymised peer review)

## Contents

| File | Description |
|---|---|
| `Online Resource 1.pdf` | **Online Resource 1.** Supplementary figures and tables: Agile development process (Figs. S1–S2; Table S1), entity–relationship diagrams (Figs. S3–S8), architectural component evidence (Table S2), additional interfaces (Figs. S9–S11) and browser and accessibility checks (Table S3). |
| `Online Resource 2.zip` | **Online Resource 2.** Evidence for the pre-deployment technical verification (Section 5 and Table 6): results workbook, machine-readable test logs, safety-review records and supporting verification evidence. A `README.txt` inside the archive describes each file, and `SHA256SUMS.txt` lists checksums for every file. |

## Notes

- All checks used synthetic accounts and records on a local installation; no real learner or teacher data are included.
- Author identities are withheld for anonymised review.
